# دليل استخدام Locara على Windows

## 1. التشغيل
فك ضغط `Locara-windows-x64.zip` في أي مجلد على جهازك وشغّل `Locara.Desktop.exe`. النسخة مستقلة ولا تحتاج إلى تثبيت .NET.

---

## 2. فتح اللعبة وفحص النصوص
1. من تبويب **«مشاريعي»**، اختر اللعبة مباشرة من **مكتبة Steam**، أو اسحب مجلد اللعبة وأسقطه داخل النافذة، أو اضغط **«مشروع جديد»**.
2. يفحص Locara المجلد تلقائياً ويستخرج ملفات الترجمة القابلة للتعديل، مع تجاهل ملفات اللغات غير الإنجليزية والملفات التقنية لتوفير الوقت.
3. إذا كانت اللعبة من **Unreal Engine** وحزم `.pak` فيها مشفّرة بمفتاح AES-256، افتح **«خيارات متقدمة»** في تبويب **«الملفات»** وألصق المفتاح ثم أعد الفحص.
4. يمكنك مراجعة الملفات وتفعيل أو استبعاد أي ملف من تبويب **«الملفات»**، أو استخدام زر **«تحليل ذكي (AI Scout)»** لمساعدتك في تحديد الحقول النصية داخل الملفات المختلطة.

---

## 3. الترجمة والمراجعة
- **الترجمة اليدوية:** افتح تبويب **«المحرّر»** للبحث والتعديل والاعتماد، أو صدّر النصوص إلى CSV وأعد استيرادها بعد المراجعة.
- **الترجمة بالذكاء الاصطناعي:** من تبويب **«الترجمة والوكلاء»** أضف مزوّدك (Gemini أو Anthropic أو DeepSeek أو Azure أو خادم OpenAI محلي)، واختر النموذج وأسلوب الترجمة المناسب لنوع اللعبة، ثم ابدأ التشغيل. يمكنك الإيقاف المؤقت والاستئناف في أي وقت، كما يُحفظ مفتاح الـ API داخل Windows Credential Manager.

---

## 4. الخطوط، التجربة، والتثبيت
من تبويب **«الحزم والتجربة»**:
- اختر الخط العربي المناسب من الخطوط المدمجة أو أضف ملف خط `.ttf` / `.otf` من جهازك.
- لألعاب **Unity** يمكنك ضبط حجم الخط، وطريقة التفاف الأسطر، وتعزيز التباين، أو تعطيل تشكيل الحروف إذا كانت اللعبة تدعم العربية أصلاً. وللألعاب التي تخزّن نصوصها داخل الكود يمكنك التصدير بصيغة **XUnity.AutoTranslator (BepInEx)**.
- لألعاب **Gettext (`.pot`)** يمكنك اختيار تطبيق الترجمة مباشرة على أحد ملفات `.po` المثبّتة في اللعبة أو تصدير ملف عربي مستقل.
- اضغط **«جرّب داخل اللعبة»** للتشغيل المؤقت عبر Steam مع استعادة تلقائية للملفات عند الإغلاق، أو **«تثبيت دائم داخل اللعبة»** للتثبيت مع نسخة احتياطية كاملة يمكن استعادتها بضغطة زر.

---

## التحقق من سلامة الملف (SHA-256)
لمقارنة بصمة الحزمة مع ملف `Locara-windows-x64.zip.sha256` في PowerShell:

</div>

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Locara-windows-x64.zip
```
