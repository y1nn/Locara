# دليل تشغيل **Locara** على Windows x64

فك ضغط حزمة `Locara-windows-x64.zip` في أي مجلد تملك صلاحية الكتابة فيه، ثم شغّل **`Locara.Desktop.exe`** مباشرةً (نسخة مستقلة لا تتطلب تثبيت .NET منفصل).

---

## 1. البدء السريع (إنشاء مشروع وفحص اللعبة)

1. افتح تبويب **«مشاريعي»** واختر لعبتك مباشرة من **مكتبة Steam**، أو اسحب مجلد اللعبة / ملف اللغة وأسقطه داخل النافذة، أو اضغط **«مشروع جديد»** لاختيار المجلد يدوياً.
2. يفحص Locara اللعبة تلقائياً، ويتعرّف على المحرك والحزمة الرئيسية (مثل `.pck` لألعاب Godot، أو `.pak`/`.locres` لـ Unreal، أو `data.unity3d`/`.bundle`/`resources.assets` لـ Unity).
3. راجع تبويب **«الملفات» (حارس الجودة واللغات)**:
   - يستبعد Locara تلقائياً الملفات التقنية والبرمجية، وكذلك حزم اللغات غير الإنجليزية عند توفر الإنجليزية، لحماية اللعبة وتوفير رصيدك.
   - يمكنك تفعيل أو إلغاء أي ملف يدوياً بضغطة واحدة.

---

## 2. الترجمة والمراجعة (يدوياً أو بفريق الذكاء الاصطناعي)

- **يدوياً:** افتح تبويب **«المحرّر»** للبحث والتعديل واعتماد النصوص، أو استخدم تصدير/استيراد CSV.
- **عبر فريق الذكاء الاصطناعي (تبويب «الترجمة والوكلاء»):**
  1. أضف ملف اتصال API (يدعم **Gemini**، **Anthropic**، **DeepSeek**، **OpenAI-compatible** بما فيها الخوادم المحلية مع التحقق من بصمة شهادة HTTPS، و**Azure**). تُحفظ مفاتيح الـ API بأمان داخل Windows Credential Manager.
  2. يمكنك توزيع نماذج أو اتصالات مختلفة للمترجم والمراجع والمشرف، أو حتى لكل وكيل على حدة (`وكيل #1..#16`).
  3. اضبط عدد الوكلاء وحجم الدفعة (يُوصى بـ **20–30 نصاً** للدفعة للاستقرار وتقليل الإعادات)، وأضف مصطلحات لعبتك في **المعجم** وأسلوب الترجمة في **تعليمات الأسلوب والأدوار**.
  4. يدعم الفريق الإيقاف المؤقت والاستئناف الفوري وإعادة محاولة انقطاعات الشبكة المؤقتة تلقائياً، مع سجل استهلاك تراكمي للتوكنز والتكلفة التقديرية لكل نموذج.

---

## 3. الخطوط والعرض العربي (تبويب «الحزم والتجربة»)

- يضم Locara خطوطاً عربية مفتوحة المصدر جاهزة (**Noto Sans Arabic**، **Noto Naskh Arabic**، **IBM Plex Sans Arabic**، **Amiri** بترخيص SIL OFL 1.1) بالإضافة إلى خطوط Windows وإمكانية استيراد أي خط `.ttf`/`.otf` خاص مع معاينة فورية.
- **لألعاب Unity (TextMeshPro):**
  - يُحقن الخط العربي الاحتياطي تلقائياً في `resources.assets` / `data.unity3d` مع تشكيل الحروف والالتفاف الذكي للأسطر الطويلة (لمنع انقلاب الفقرات من أسفل لأعلى).
  - يمكنك ضبط عرض الالتفاف وحجم الخط (`70%–110%`)، أو إيقاف التشكيل المسبق إذا كانت اللعبة تدعم RTL أصلياً.
  - للألعاب ذات النصوص المدمجة في الكود البرمجي (Hardcoded C#/IL2CPP): استخدم زر **«تصدير XUnity.AutoTranslator (BepInEx)»** أو افتح ملف `_AutoGeneratedTranslations.txt` مباشرة داخل Locara.
- **لألعاب Unreal Engine 4 & 5:**
  - تُكتب النصوص العربية بترميز `UTF-16LE` المنطقي (مع دعم HarfBuzz/ICU الأصلي) ويُحقن خط ثنائي عربي+لاتيني تلقائياً (بإنشاء حزمة تعديل جاهزة `*_Locara_P.pak` أو بالتدفق المباشر لحزم **UE5 IoStore**).
- **لألعاب Godot 3 & 4 (بما فيها 4.5+):**
  - يدعم حزم **`PCK v2` و`PCK v3`** وملفات **`.translation`** الثنائية (`OptimizedTranslation` / `PHashTranslation` و`Translation`) مع العرض العربي الأصلي في Godot 4.

---

## 4. التجربة داخل اللعبة والتثبيت الدائم الآمن

- **«جرّب داخل اللعبة»:** يشغّل ألعاب Steam (Unity، Unreal، Godot، Star Trucker) عبر Steam مؤقتاً مع حفظ الملفات الأصلية واستعادتها تلقائياً فور إغلاق اللعبة.
- **«تثبيت دائم داخل اللعبة (مع نسخة احتياطية)»:** يثبّت التعريب مباشرة مع حفظ نسخة احتياطية مؤكدة ببصمة SHA-256 داخل المشروع، ويكشف أي تحديث رسمي للعبة، ويتيح إزالة التعريب واستعادة الأصل بضغطة واحدة.

---

## التحقق من بصمة حزمة الإصدار (SHA-256)

للتحقق من سلامة ملف `Locara-windows-x64.zip` ومقارنته بملف `Locara-windows-x64.zip.sha256`، شغّل الأمر التالي في PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Locara-windows-x64.zip
```
