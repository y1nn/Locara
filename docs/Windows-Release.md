# دليل استخدام Locara على Windows

## 1. التشغيل
فك ضغط `Locara-windows-x64.zip` في أي مجلد على جهازك وشغّل `Locara.Desktop.exe`. النسخة مستقلة ولا تحتاج إلى تثبيت .NET.

---

## 2. فتح اللعبة وفحص النصوص
1. من صفحة **«مكتبتي والمشاريع»**، اختر اللعبة مباشرة من **مكتبة Steam**، أو اسحب مجلد اللعبة وأفلته داخل بطاقة الإسقاط، أو اضغط **«+ مشروع جديد»**.
2. يفحص Locara المجلد تلقائياً في مرحلة **«1. المصدر والملفات»** ويستخرج ملفات الترجمة القابلة للتعديل، مع عزل ملفات اللغات غير الإنجليزية والملفات التقنية لتوفير الوقت.
3. إذا كانت اللعبة من **Unreal Engine** وحزم `.pak` فيها مشفّرة بمفتاح AES-256، افتح **«خيارات المصدر المتقدمة»** في مرحلة **«1. المصدر والملفات»** وألصق المفتاح ثم أعد الفحص.
4. يمكنك مراجعة الملفات وتفعيل أو استبعاد أي ملف ومعاينة نصوصه مباشرة، أو استخدام زر **«تحليل ذكي (AI Scout)»** لمساعدتك في تحديد الحقول النصية داخل الملفات المختلطة.

---

## 3. البوتات والترجمة والمراجعة
- **غرفة البوتات الذكية المترابطة («2. البوتات والترجمة»):**
  - أضف ملف اتصال الـ API الخاص بك من **«الإعدادات ومفاتيح API»** (Gemini أو Anthropic أو DeepSeek أو Azure أو أي خادم متوافق مع OpenAI — يُحفظ المفتاح مشفّراً داخل Windows Credential Manager).
  - تعمل 3 بوتات متخصصة بترابط كامل: **بوت الكشّاف والعالم** (يبني بطاقة عالم اللعبة والمسرد التلقائي)، و**بوتات المشاهد المتسلسلة** (بجلسات محادثة متصلة وذاكرة سياق متحركة ومشاركة فورية للمصطلحات)، و**بوت المدقق السياقي**.
  - يمكنك الإيقاف المؤقت الآمن والاستئناف في أي وقت، ومراجعة بطاقة عالم اللعبة وتثبيت المصطلحات المكتشفة في معجمك اليدوي.
- **المحرّر والمراجعة («3. المحرّر والمراجعة»):** محرّر مقسّم مع لوحة سياق المشهد المحيط، وإدراج الرموز المحمية بنقرة، والاعتماد السريع (`Ctrl+Enter`)، وتصدير/استيراد CSV.

---

## 4. الخطوط، التجربة، والتثبيت
من مرحلة **«4. الخط والتثبيت»**:
- اختر الخط العربي المناسب من الخطوط المدمجة أو أضف ملف خط `.ttf` / `.otf` من جهازك مع معاينة حية لشاشة اللعبة.
- لألعاب **Unity** يمكنك ضبط حجم الخط، وطريقة التفاف الأسطر، وتعزيز التباين، أو تعطيل تشكيل الحروف إذا كانت اللعبة تدعم العربية أصلاً (كما يدعم التشكيل التلقائي ألعاب Unity الكلاسيكية دون TextMeshPro). وللألعاب التي تخزّن نصوصها داخل الكود يمكنك التصدير بصيغة **XUnity.AutoTranslator (BepInEx)**.
- لألعاب **Gettext (`.pot`)** يمكنك اختيار تطبيق الترجمة مباشرة على أحد ملفات `.po` المثبّتة في اللعبة أو تصدير ملف عربي مستقل.
- اضغط **«ثبّت التعريب داخل اللعبة (مع نسخة احتياطية)»** للتثبيت الذكي مع بصمة SHA-256 واستعادة بضغطة زر، أو **«تجربة مؤقتة وتستعاد تلقائياً»** عبر Steam.

---

## التحقق من سلامة الملف (SHA-256)
لمقارنة بصمة الحزمة مع ملف `Locara-windows-x64.zip.sha256` في PowerShell:

</div>

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Locara-windows-x64.zip
```
