# دليل تشغيل **Locara** على Windows x64

فك ضغط حزمة `Locara-windows-x64.zip` في أي مجلد تملك صلاحية الكتابة فيه، ثم شغّل **`Locara.Desktop.exe`** مباشرةً (نسخة مستقلة لا تتطلب تثبيت .NET منفصل).

---

## 1. البدء السريع والاكتشاف الذكي (3 طبقات)

1. افتح تبويب **«مشاريعي»** واختر لعبتك مباشرة من **مكتبة Steam**، أو اسحب مجلد اللعبة / ملف اللغة وأسقطه داخل النافذة، أو اضغط **«مشروع جديد»** لاختيار المجلد يدوياً.
2. يفحص Locara اللعبة تلقائياً، ويتعرّف على المحرك والحزمة الرئيسية (**Unity**، **Unreal Engine 4/5**، **Godot 3/4.5+**، **Ren’Py**، **RPG Maker**، **GameMaker**، والصيغ القياسية `JSON`/`CSV`/`XML`/`YAML`/`TOML`/`.strings`/`Lua`/`PO`/`POT`/`XLSX`).
3. راجع تبويب **«الملفات» (الاكتشاف الذكي وحارس الجودة من 3 طبقات)**:
   - **الطبقة 1 (محلياً وبلا تكلفة):** يعطي الأولوية لملفات الترجمة المخصّصة، ويتخطّى تحليل ملفات اللغات غير الإنجليزية تلقائياً لتسريع فحص الحزم الضخمة (مع استخراجها فوراً عند تفعيل أيٍّ منها يدوياً)، ويستبعد الملفات التقنية والجانبية، ويتيح زر **«تفعيل النصوص البشرية فقط في هذا الملف»** للملفات المختلطة.
   - **الطبقة 2 — تحليل ذكي (AI Scout اختياري):** اضغط **«تحليل ذكي (AI Scout)»** لإرسال ملخص هيكلي مضغوط جداً للقوالب المختلطة إلى مزوّد الذكاء الاصطناعي لاقتراح الحقول النصية البشرية فقط ومراجعتها قبل التطبيق.
   - **الطبقة 3 — مستشار التسليم:** ينبّهك تلقائياً لأفضل طريقة تسليم (مثل تحويل قوالب Gettext `.pot` إلى ملف `.po` مثبّت، أو استخدام `XUnity.AutoTranslator` لألعاب Unity المدمجة نصوصها في الكود).

---

## 2. الترجمة والمراجعة (يدوياً أو بفريق الذكاء الاصطناعي)

- **يدوياً:** افتح تبويب **«المحرّر»** للبحث والتعديل واعتماد النصوص، أو استخدم تصدير/استيراد CSV.
- **عبر فريق الذكاء الاصطناعي (تبويب «الترجمة والوكلاء»):**
  1. أضف ملف اتصال API (يدعم **Gemini**، **Anthropic**، **DeepSeek**، **OpenAI-compatible** بما فيها الخوادم المحلية مع التحقق من بصمة شهادة HTTPS، و**Azure**). تُحفظ مفاتيح الـ API بأمان داخل Windows Credential Manager.
  2. يمكنك توزيع نماذج أو اتصالات مختلفة للمترجم والمراجع والمشرف، أو حتى لكل وكيل على حدة (`وكيل #1..#16`).
  3. افتح قسم **«تعليمات الأسلوب والأدوار»** واختر أحد **قوالب الأسلوب العربية الـ 6 الجاهزة** (متوازن قياسي، قصصي وسينمائي RPG، حركي ومقتضب للواجهات، خيال علمي وتقني، فانتازيا ملحمية، أو خفيف وكوميدي) بضغطة زر، وأضف مصطلحات لعبتك في **المعجم**.
  4. يدعم الفريق الإيقاف المؤقت والاستئناف الفوري وإعادة محاولة انقطاعات الشبكة المؤقتة تلقائياً، مع سجل استهلاك تراكمي للتوكنز والتكلفة التقديرية لكل نموذج.

---

## 3. الخطوط والعرض العربي (تبويب «الحزم والتجربة»)

- يضم Locara خطوطاً عربية مفتوحة المصدر جاهزة (**Noto Sans Arabic**، **Noto Naskh Arabic**، **IBM Plex Sans Arabic**، **Amiri** بترخيص SIL OFL 1.1) بالإضافة إلى خطوط Windows وإمكانية استيراد أي خط `.ttf`/`.otf` خاص مع معاينة فورية.
- **لألعاب Unity (TextMeshPro والخطوط المفتوحة):**
  - يُحقن الخط العربي الاحتياطي تلقائياً في `resources.assets` / `data.unity3d` (أو يُحقن خط ثنائي عربي+لاتيني في خطوط `fonts/*.ttf` المفتوحة عند غياب TMP)، مع تشكيل الحروف والالتفاف الذكي المتوازن الذي يحمي الوسوم المتداخلة ووسوم `<link>`.
  - يمكنك ضبط عرض الالتفاف وحجم الخط (`70%–110%`)، وتفعيل **«تعزيز وضوح وتباين الحروف العربية على الأزرار الفاتحة»** (ترقية تلقائية للوزن العريض وتمديد حواف SDF)، أو إيقاف التشكيل المسبق إذا كانت اللعبة تدعم RTL أصلياً.
  - للألعاب ذات النصوص المدمجة في الكود البرمجي (Hardcoded C#/IL2CPP): استخدم زر **«تصدير XUnity.AutoTranslator (BepInEx)»** أو افتح ملف `_AutoGeneratedTranslations.txt` مباشرة داخل Locara.
- **لألعاب Unreal Engine 4 & 5:**
  - يقرأ ويكتب ملفات **`.locres`** وجداول **`StringTable` (`.uasset`/`.uexp`)** المفتوحة أو داخل حزم **`.pak`** بترميز `UTF-16LE` المنطقي، ويحقن خطاً ثنائياً عربياً+لاتينياً تلقائياً (بإنشاء حزمة تعديل جاهزة `*_Locara_P.pak` أو بالتدفق المباشر لحزم **UE5 IoStore**).
- **لألعاب Godot 3 & 4 (بما فيها 4.5+):**
  - يدعم حزم **`PCK v2` و`PCK v3`** وملفات **`.translation`** الثنائية (`RSRC` و`RSCC` بجميع أنماط ضغطها: `Zstd`، `FastLZ`، `Zlib`، `Gzip`) مع العرض العربي الأصلي في Godot 4.

---

## 4. التجربة داخل اللعبة والتثبيت الدائم الآمن

- **«جرّب داخل اللعبة»:** يشغّل ألعاب Steam (Unity، Unreal، Godot، GameMaker، Star Trucker) عبر Steam مؤقتاً مع حفظ الملفات الأصلية واستعادتها تلقائياً فور إغلاق اللعبة.
- **«تثبيت دائم داخل اللعبة (مع نسخة احتياطية)»:** يثبّت التعريب مباشرة مع حفظ نسخة احتياطية مؤكدة ببصمة SHA-256 داخل المشروع، ويكشف أي تحديث رسمي للعبة، ويتيح إزالة التعريب واستعادة الأصل بضغطة واحدة.

---

## التحقق من بصمة حزمة الإصدار (SHA-256)

للتحقق من سلامة ملف `Locara-windows-x64.zip` ومقارنته بملف `Locara-windows-x64.zip.sha256`، شغّل الأمر التالي في PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Locara-windows-x64.zip
```
